# HabitBot

HabitBot — это Telegram-бот для формирования полезных привычек.

## О проекте

Этот бот помогает пользователю:
- сохранять свою привычку
- отмечать выполнение
- следить за прогрессом
- получать совет дня

Проект создан в Domino CRM.

## Цель проекта

Создать удобного Telegram-бота, который помогает человеку формировать полезные привычки и не забывать о них.

## Основные функции

- регистрация пользователя
- сохранение имени
- выбор привычки
- отслеживание серии дней
- просмотр статистики
- совет дня с использованием ИИ

## Использованные технологии

- Domino CRM
- Telegram
- ИИ-ассистент
- поля контакта и переменные

## Как работает бот

1. Пользователь запускает бота
2. Вводит своё имя
3. Выбирает привычку
4. Каждый день отмечает выполнение
5. Бот считает прогресс и показывает статистику
